# SO-101 セットアップガイド

このドキュメントは TeachArm で使用する SO-101 ロボットアームのセットアップ手順をまとめたものです。

## SO-101 概要

SO-101 は教育用の 6 自由度ロボットアームで、Feetech STS3215 サーボモーターを使用します。

### モーター構成

| 関節ID | 関節名 | ギア比 | 用途 |
|--------|--------|--------|------|
| 1 | shoulder_pan (ベース回転) | 1/191 | 左右旋回 |
| 2 | shoulder_lift (肩上下) | 1/345 | 肩の上下動 |
| 3 | elbow_flex (肘屈曲) | 1/191 | 肘の曲げ伸ばし |
| 4 | wrist_flex (手首屈曲) | 1/147 | 手首の曲げ |
| 5 | wrist_roll (手首回転) | 1/147 | 手首の回転 |
| 6 | gripper (グリッパー) | 1/147 | つかむ動作 |

Follower アーム（制御対象）は全てのモーターが STS3215 を使用します。

Leader アーム（操作用）は一部のモーターでギア比が異なります（操作性とトルクのバランス）。

**参考**: [LeRobot SO-101 Documentation](https://huggingface.co/docs/lerobot/en/so101)

## 必要なもの

### ハードウェア
- SO-101 キット（3Dプリント部品 + モーター）
- USB シリアルアダプタ（モーターバス接続用）
- 電源アダプタ（モーター駆動用）

### ソフトウェア
- Python 3.11+
- LeRobot ライブラリ（Feetech SDK 含む）

## セットアップ手順

### 1. LeRobot のインストール

```bash
# SO-101 用の別環境で実行（faster-whisper と依存衝突するため）
pip install -r requirements/arm.txt
```

macOS で `lerobot[feetech]` と `faster-whisper` が衝突する場合は、
SO-101 専用の Python 3.11 環境を分けて用意してください。

```bash
python3.11 -m venv .venv-so101
source .venv-so101/bin/activate
pip install -r requirements/arm.txt
python scripts/move_arm.py --status
```

### 2. USB ポートの確認

SO-101 をコンピュータに接続し、ポートを確認します。

```bash
# macOS/Linux
lerobot-find-port

# 出力例:
# Finding all available ports for the MotorBus.
# ['/dev/tty.usbmodem575E0032081', '/dev/tty.usbmodem575E0031751']
# Remove the USB cable from your MotorsBus and press Enter when done.
```

最後のメッセージは、USBケーブルを抜いてEnterキーを押すというメッセージ
表示されたポート（例: `/dev/tty.usbmodem575E0032081`）をメモしてください。
USB の差し替えや再起動でポート名が変わることがあるため、毎回 `lerobot-find-port` で確認するのが安全です。

### 3. モーター ID とボーレートの設定

各モーターに一意の ID を設定する必要があります（新品のモーターは通常 ID=1 でデフォルト設定されています）。

**メモ**: すでに別の PC で動作していた SO-101 であれば、ID はモーター本体に保存されているため、この手順は基本的にスキップ可能です。`lerobot-setup-motors` 実行中であっても中断して構いません。

**重要**: この作業は各モーターを**個別に**接続して行います。

以下をUSB シリアルアダプタを接続した状態で実行します。
```bash
# Follower アーム（制御対象）の設定
lerobot-setup-motors \
    --robot.type=so101_follower \
    --robot.port=/dev/tty.usbmodem575E0032081  # 前のステップで確認したポート
```

実行後はターミナルの指示に従い、モーターを 1 台ずつ単独で接続してください。

### 3.1 既存機体の再接続（ID 設定スキップ時）

別の PC で運用していた SO-101 をこの PC で動かす場合は、以下の手順で確認します。

1. USB ポート確認:
   ```bash
   lerobot-find-port
   ```
2. `.env` の `SO101_PORT` を更新
3. 動作確認:
   ```bash
   python scripts/move_arm.py --status
   ```
   もしくは
   ```bash
   python scripts/move_arm.py --safe-pose
   ```

`--status` で読めない/動かない場合のみ、ID 設定に戻ってください。

```text
# 出力例（メッセージは環境で変わります）
# Motor setup started for so101_follower.
# Connect only gripper (ID=6) then press Enter.
```

ターミナルの指示（`lerobot-setup-motors` の出力）に従い、以下の順序でモーターを接続します：

1. **gripper** (ID=6) のみを接続 → Enter
2. **wrist_roll** (ID=5) のみを接続 → Enter
3. **wrist_flex** (ID=4) のみを接続 → Enter
4. **elbow_flex** (ID=3) のみを接続 → Enter
5. **shoulder_lift** (ID=2) のみを接続 → Enter
6. **shoulder_pan** (ID=1) のみを接続 → Enter

各ステップで、モーターを制御ボードに**単独で**接続し、他のモーターとデイジーチェーン接続されていないことを確認してください。

完了後、モーター同士を 3 ピンケーブルで接続し、ID=1 のモーターを制御ボードに接続します。

### 4. キャリブレーション

各関節の可動範囲とオフセットを記録します。これにより、異なる SO-101 ユニット間で一貫した動作が可能になります。

```bash
lerobot-calibrate \
    --robot.type=so101_follower \
    --robot.port=/dev/tty.usbmodem58760431551 \
    --robot.id=teacharm_follower
```

**キャリブレーション手順**:
1. 全ての関節を可動範囲の中央に移動（手動）
2. Enter を押す
3. 各関節を可動範囲全体で動かす（ターミナルの指示に従う。`lerobot-calibrate` の出力）

キャリブレーションデータは自動的に保存されます。

## TeachArm での設定

### config/arm_limits.json

SO-101 の関節制限と安全姿勢を設定します。

```json
{
  "robot_type": "so101_follower",
  "motor_config": {
    "baudrate": 1000000,
    "joints": [
      {"id": 1, "name": "shoulder_pan", "gear_ratio": "1/191", "min_deg": -90, "max_deg": 90},
      {"id": 2, "name": "shoulder_lift", "gear_ratio": "1/345", "min_deg": -45, "max_deg": 90},
      {"id": 3, "name": "elbow_flex", "gear_ratio": "1/191", "min_deg": -120, "max_deg": 0},
      {"id": 4, "name": "wrist_flex", "gear_ratio": "1/147", "min_deg": -90, "max_deg": 90},
      {"id": 5, "name": "wrist_roll", "gear_ratio": "1/147", "min_deg": -180, "max_deg": 180},
      {"id": 6, "name": "gripper", "gear_ratio": "1/147", "min_deg": 0, "max_deg": 60}
    ]
  },
  "safe_pose": {
    "type": "joint_angles",
    "angles": [0.0, 45.0, -45.0, 0.0, 0.0, 30.0]
  }
}
```

**注**: `min_deg` と `max_deg` の値はキャリブレーション後に実測してください。上記は参考値です。

### .env ファイル

SO-101 の USB ポートを環境変数に設定します。

```bash
# SO-101 Follower Arm
SO101_PORT=/dev/tty.usbmodem575E0032081
```

### TeachArm からの操作

`scripts/move_arm.py` を使うと、関節角やセーフポーズを簡単に実行できます。

```bash
# 関節角で動かす
python scripts/move_arm.py --joints 0 45 -45 0 0 20 --speed 0.2

# セーフポーズ
python scripts/move_arm.py --safe-pose

# 現在角を取得
python scripts/move_arm.py --status
```

API 経由で動かす場合は以下を使用します。

```bash
curl -X POST http://localhost:8000/api/arm/safe_pose
```

FK（関節角 -> 先端位置）の計算は `scripts/so101_fk.py` で確認できます。

```bash
python scripts/so101_fk.py --joints 0 45 -45 0 0
```

## 実機統合

`teacharm/services/arm.py` は LeRobot SDK による実機制御を前提としています。実機を接続する際は以下を確認してください：

1. **LeRobot SDK の統合**
   ```python
   from lerobot.common.robot_devices.motors.feetech import FeetechMotorsBus
   ```

2. **モーターバスの初期化**
   ```python
   self._motor_bus = FeetechMotorsBus(
       port=port,
       motors=SO101_JOINTS
   )
   await self._motor_bus.connect()
   ```

3. **関節角度の読み書き**
   ```python
   # 読み取り
   positions = await self._motor_bus.read("Present_Position")
   
   # 書き込み
   await self._motor_bus.write("Goal_Position", target_angles)
   ```

4. **逆運動学（IK）の実装**
   - Cartesian 座標 (x, y, z) から関節角度への変換
   - SO-101 のキネマティクスパラメータが必要
   - 現在は `move_to` が IK 未実装のため、関節角指定で操作してください

### URDF による IK/FK パラメータ

URDF は SO-ARM100 の `Simulation/SO101/so101_new_calib.urdf` を参照しています（https://github.com/TheRobotStudio/SO-ARM100/blob/main/Simulation/SO101/so101_new_calib.urdf）。
IK/FK に必要な **関節順・親子リンク・origin・axis・limit・tool フレーム** が揃っているため、
実測なしでパラメータを確定できます（単位は m）。

最小構成のチェーン（腕のみ、gripper 開閉は別扱い）:

```
base_link
  -> shoulder_pan (revolute)
  -> shoulder_lift (revolute)
  -> elbow_flex (revolute)
  -> wrist_flex (revolute)
  -> wrist_roll (revolute)
  -> gripper_frame_joint (fixed) -> gripper_frame_link
```

補足:
- revolute の回転軸は全て `axis="0 0 1"`。
- tool フレーム候補は `gripper_frame_link`（固定 joint でオフセットが明示）。
- gripper は開閉用の独立関節として IK から分離するのが自然。

### IK 実装の雛形（最低限）

IK はロボット寸法に依存するため、まずは **実機のリンク長** を測ってから実装します。
以下は最低限の構成例です（角度の並びは `JointCommand` に合わせる）。

```python
def solve_ik(x: float, y: float, z: float) -> list[float]:
    # TODO: ロボット寸法 (L1, L2, L3...) を実測して定義
    # TODO: 角度制約・可動域チェックを入れる
    base = math.degrees(math.atan2(y, x))
    shoulder = 0.0
    elbow = 0.0
    wrist = 0.0
    wrist_roll = 0.0
    gripper = 0.0
    return [base, shoulder, elbow, wrist, wrist_roll, gripper]
```

補足:
- TeachArm の `move_to` は URDF パラメータを使った数値IK（CCD）です。
- 先端の姿勢は合わせず、位置のみを解きます。
- 収束しない場合は関節角指定で操作してください。

## トラブルシューティング

### モーターが検出されない
- USB ケーブルの接続を確認
- 電源アダプタが接続されているか確認
- `lerobot-find-port` でポートが表示されるか確認

### ID 設定に失敗する
- モーターが**単独で**接続されているか確認（デイジーチェーン接続されていないこと）
- 電源ケーブルが接続されているか確認
- モーターの初期 ID が 1 であることを確認

### キャリブレーションがうまくいかない
- 各関節をゆっくり、可動範囲全体で動かす
- 関節が物理的に干渉していないか確認

### モーターが動かない
- トルクが有効になっているか確認
- 関節制限内の角度を指定しているか確認
- バッテリー/電源の電圧を確認
