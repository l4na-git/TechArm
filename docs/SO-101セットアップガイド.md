# SO-101 セットアップガイド

このドキュメントは TeachArm で使用する SO-101 ロボットアームのセットアップ手順をまとめたものです。

## SO-101 概要

SO-101 は教育用の 6 自由度ロボットアームで、Feetech STS3215 サーボモーターを使用します。

### モーター構成

| 関節ID | 関節名 | ギア比 | 用途 |
|--------|--------|--------|------|
| 1 | shoulder_pan (ベース回転) | 1/191 | 左右旋回 |
| 2 | shoulder_lift (肩上下) | 1/345 | 肩の上下動 |
| 3 | elbow_flex (肘屈曲) | 1/191 | 肘の曲げ伸ばし |
| 4 | wrist_flex (手首屈曲) | 1/147 | 手首の曲げ |
| 5 | wrist_roll (手首回転) | 1/147 | 手首の回転 |
| 6 | gripper (グリッパー) | 1/147 | つかむ動作 |

Follower アーム（制御対象）は全てのモーターが STS3215 を使用します。

Leader アーム（操作用）は一部のモーターでギア比が異なります（操作性とトルクのバランス）。

**参考**: [LeRobot SO-101 Documentation](https://huggingface.co/docs/lerobot/en/so101)

## 必要なもの

### ハードウェア
- SO-101 キット（3Dプリント部品 + モーター）
- USB シリアルアダプタ（モーターバス接続用）
- 電源アダプタ（モーター駆動用）

### ソフトウェア
- Python 3.11+
- LeRobot ライブラリ（Feetech SDK 含む）

## セットアップ手順

### 1. LeRobot のインストール

```bash
# TeachArm の仮想環境で実行
source .venv/bin/activate

# Feetech SDK を含む LeRobot をインストール
pip install -e ".[feetech]"
```

### 2. USB ポートの確認

SO-101 をコンピュータに接続し、ポートを確認します。

```bash
# macOS/Linux
lerobot-find-port

# 出力例:
# Finding all available ports for the MotorBus.
# ['/dev/tty.usbmodem575E0032081', '/dev/tty.usbmodem575E0031751']
# Remove the USB cable from your MotorsBus and press Enter when done.
```

表示されたポート（例: `/dev/tty.usbmodem575E0032081`）をメモしてください。

### 3. モーター ID とボーレートの設定

各モーターに一意の ID を設定する必要があります（新品のモーターは通常 ID=1 でデフォルト設定されています）。

**重要**: この作業は各モーターを**個別に**接続して行います。

```bash
# Follower アーム（制御対象）の設定
lerobot-setup-motors \
    --robot.type=so101_follower \
    --robot.port=/dev/tty.usbmodem575E0032081  # 前のステップで確認したポート
```

画面の指示に従い、以下の順序でモーターを接続します：

1. **gripper** (ID=6) のみを接続 → Enter
2. **wrist_roll** (ID=5) のみを接続 → Enter
3. **wrist_flex** (ID=4) のみを接続 → Enter
4. **elbow_flex** (ID=3) のみを接続 → Enter
5. **shoulder_lift** (ID=2) のみを接続 → Enter
6. **shoulder_pan** (ID=1) のみを接続 → Enter

各ステップで、モーターを制御ボードに**単独で**接続し、他のモーターとデイジーチェーン接続されていないことを確認してください。

完了後、モーター同士を 3 ピンケーブルで接続し、ID=1 のモーターを制御ボードに接続します。

### 4. キャリブレーション

各関節の可動範囲とオフセットを記録します。これにより、異なる SO-101 ユニット間で一貫した動作が可能になります。

```bash
lerobot-calibrate \
    --robot.type=so101_follower \
    --robot.port=/dev/tty.usbmodem58760431551 \
    --robot.id=teacharm_follower
```

**キャリブレーション手順**:
1. 全ての関節を可動範囲の中央に移動（手動）
2. Enter を押す
3. 各関節を可動範囲全体で動かす（画面の指示に従う）

キャリブレーションデータは自動的に保存されます。

## TeachArm での設定

### config/arm_limits.json

SO-101 の関節制限と安全姿勢を設定します。

```json
{
  "robot_type": "so101_follower",
  "motor_config": {
    "baudrate": 1000000,
    "joints": [
      {"id": 1, "name": "shoulder_pan", "gear_ratio": "1/191", "min_deg": -90, "max_deg": 90},
      {"id": 2, "name": "shoulder_lift", "gear_ratio": "1/345", "min_deg": -45, "max_deg": 90},
      {"id": 3, "name": "elbow_flex", "gear_ratio": "1/191", "min_deg": -120, "max_deg": 0},
      {"id": 4, "name": "wrist_flex", "gear_ratio": "1/147", "min_deg": -90, "max_deg": 90},
      {"id": 5, "name": "wrist_roll", "gear_ratio": "1/147", "min_deg": -180, "max_deg": 180},
      {"id": 6, "name": "gripper", "gear_ratio": "1/147", "min_deg": 0, "max_deg": 60}
    ]
  },
  "safe_pose": {
    "type": "joint_angles",
    "angles": [0.0, 45.0, -45.0, 0.0, 0.0, 30.0]
  }
}
```

**注**: `min_deg` と `max_deg` の値はキャリブレーション後に実測してください。上記は参考値です。

### .env ファイル

SO-101 の USB ポートを環境変数に設定します。

```bash
# SO-101 Follower Arm
SO101_PORT=/dev/tty.usbmodem575E0032081
```

## 実機統合

現在の `teacharm/services/arm.py` は stub 実装です。実機を接続する際は以下を実装してください：

1. **LeRobot SDK の統合**
   ```python
   from lerobot.common.robot_devices.motors.feetech import FeetechMotorsBus
   ```

2. **モーターバスの初期化**
   ```python
   self._motor_bus = FeetechMotorsBus(
       port=port,
       motors=SO101_JOINTS
   )
   await self._motor_bus.connect()
   ```

3. **関節角度の読み書き**
   ```python
   # 読み取り
   positions = await self._motor_bus.read("Present_Position")
   
   # 書き込み
   await self._motor_bus.write("Goal_Position", target_angles)
   ```

4. **逆運動学（IK）の実装**
   - Cartesian 座標 (x, y, z) から関節角度への変換
   - SO-101 のキネマティクスパラメータが必要

## トラブルシューティング

### モーターが検出されない
- USB ケーブルの接続を確認
- 電源アダプタが接続されているか確認
- `lerobot-find-port` でポートが表示されるか確認

### ID 設定に失敗する
- モーターが**単独で**接続されているか確認（デイジーチェーン接続されていないこと）
- 電源ケーブルが接続されているか確認
- モーターの初期 ID が 1 であることを確認

### キャリブレーションがうまくいかない
- 各関節をゆっくり、可動範囲全体で動かす
- 関節が物理的に干渉していないか確認

### モーターが動かない
- トルクが有効になっているか確認
- 関節制限内の角度を指定しているか確認
- バッテリー/電源の電圧を確認
