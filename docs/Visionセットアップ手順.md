# Vision機能 セットアップ手順

## 1. ArUcoマーカーの準備

### マーカーを生成

```bash
cd /path/to/TechArm
uv run python tools/generate_aruco_markers.py
```

生成されたマーカーは `aruco_markers/` フォルダに保存されます。

### マーカーを印刷

以下の4つのPNG画像を印刷してください：
- `aruco_marker_0_top-left.png`
- `aruco_marker_1_top-right.png`
- `aruco_marker_2_bottom-right.png`
- `aruco_marker_3_bottom-left.png`

**印刷設定:**
- サイズ: A5またはA4（5cm × 5cm程度）
- カラー: 白黒でOK
- 用紙: 普通紙でOK（光沢紙は避ける）

### マーカーを配置

教材の四隅に以下のように配置：

```
マーカー0 (左上)            マーカー1 (右上)
    ●                           ●
    ┌───────────────────────────┐
    │                           │
    │                           │
    │      教材面（A4など）      │
    │                           │
    │                           │
    └───────────────────────────┘
    ●                           ●
マーカー3 (左下)            マーカー2 (右下)
```

**配置のポイント:**
- マーカーは教材面の四隅に平面的に配置
- マーカーの向きは正方向（上が上）
- 4つ全てがカメラ視野内に収まるように

## 2. カメラのセットアップ

### カメラアクセス許可 (macOS)

1. デモを起動すると、カメラアクセス許可を求められます
2. システム環境設定 > セキュリティとプライバシー > カメラ
3. 使用するアプリ（ターミナル、iTerm2など）にチェックを入れる
4. ターミナルを再起動

### カメラの位置

教材とマーカーを真上から撮影できるように配置：

```
      [カメラ]
         |
         ↓
    ┌────────┐
    │ 教材   │
    │ + マーカー│
    └────────┘
```

**ポイント:**
- カメラと教材の距離: 30-50cm程度
- 真上から見下ろす角度が理想
- 照明: 明るく、影ができないように

## 3. デモの起動と確認

### デモを起動

```bash
cd /path/to/TechArm
uv run python demo_vision.py
```

### 画面の見方

**上部（ステータス表示）:**
```
Status: NOT CALIBRATED (赤) → CALIBRATED (緑)
Markers: [0, 1, 2, 3] ← 検出されたマーカーID
Hand: Not detected (オレンジ) → Detected (緑)
Method: mediapipe
Frame: 123
```

**下部（ヒント表示）:**
- オレンジ: 「マーカーを配置してcキーを押してください」
- 黄色: 「人差し指をカメラに向けてください」
- 緑: 「正常動作中」

## 4. キャリブレーション

### 手順

1. **4つのマーカーを全てカメラに映す**
   - 画面上に「Markers: [0, 1, 2, 3]」と表示されることを確認
   - マーカーに色付きの枠が表示される

2. **`c`キーを押す**
   - 「Status: CALIBRATED」（緑）に変わる
   - 画面が正規化される（マーカーが四隅に整列）

3. **失敗した場合**
   - 「❌ Calibration failed」と表示される
   - マーカーが4つ全て検出されているか確認
   - マーカーが平面上にあるか確認
   - 照明を改善してから再度 `c`キーを押す

## 5. 手検出の確認

### MediaPipe Handsの動作確認

1. **人差し指をカメラに向ける**
   - 手のひらを正面に向ける
   - 人差し指を立てる（他の指は曲げる）

2. **緑の円と十字が表示されるか確認**
   - 表示される → MediaPipe正常動作 ✓
   - 表示されない → トラブルシューティングへ

3. **座標の確認**
   - 緑の円の近くに `(0.456, 0.321)` のような座標が表示される
   - この値が0.0-1.0の範囲内であればOK

## トラブルシューティング

### 手が検出されない

**原因1: 照明不足**
- 解決策: 部屋を明るくする、デスクライトを追加

**原因2: 手の向き**
- 解決策: 手のひらをカメラに向ける
- ポイント: 手の甲ではなく、手のひらを見せる

**原因3: 距離が遠い/近い**
- 解決策: カメラから30-50cm程度の距離に手を配置
- 手が画面の20-80%を占めるくらいが理想

**原因4: MediaPipeが無効**
- 確認: 画面に「Method: mediapipe」と表示されているか
- 解決策: `config/camera.yaml` で `method: "mediapipe"` を確認

**原因5: カメラが他のアプリに使用されている**
- 解決策: Zoom、FaceTimeなどを終了

### マーカーが検出されない

**原因1: マーカーが全て映っていない**
- 解決策: カメラを引いて4つ全てを映す

**原因2: マーカーがぼやけている**
- 解決策: カメラのフォーカスを確認、印刷品質を確認

**原因3: 照明が不均一**
- 解決策: 影ができないように照明を配置

**原因4: マーカーが歪んでいる**
- 解決策: マーカーを平面に配置（曲がった紙は避ける）

### キャリブレーションが失敗する

**対処法:**
1. マーカーが4つ全て検出されているか確認（画面上のMarkers表示）
2. マーカーが平面上にあるか確認
3. 照明を改善
4. カメラの角度を調整（真上から見下ろす）
5. マーカーのサイズを大きくする（再印刷）

### デモがクラッシュする

**MediaPipe関連のエラー:**
```bash
# MediaPipeを再インストール
uv pip uninstall mediapipe
uv pip install mediapipe==0.10.9
```

**カメラアクセスエラー:**
- macOS: システム環境設定でカメラアクセスを許可
- 他のアプリがカメラを使用していないか確認

## 6. 正常動作の確認

以下が全て確認できればセットアップ完了：

- [ ] カメラ映像が表示される
- [ ] 4つのマーカーが検出される（Markers: [0, 1, 2, 3]）
- [ ] キャリブレーションが成功する（Status: CALIBRATED）
- [ ] 手をカメラに向けると緑の円が表示される
- [ ] 座標が表示される（例: (0.456, 0.321)）
- [ ] 人差し指を動かすと円が追従する

## 次のステップ

セットアップが完了したら：

1. **`s`キーでスクリーンショット**を保存して動作記録
2. **サーバーモードで使用**: `uv run python -m teacharm.main`
3. **WebSocket接続**: Control Panelからリアルタイム監視

詳細は [Vision機能ガイド](./Vision機能ガイド.md) を参照してください。
